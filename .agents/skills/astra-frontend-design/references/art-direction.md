# Art direction for expressive surfaces

Use this reference for landing pages, portfolios, editorial pages, brand sites, storefronts, and other surfaces where visual identity is part of the product.

## Find the idea in the subject

Start from the world of the product rather than from a fashionable UI style. Look for characteristic materials, language, artifacts, motion, scale, environments, or cultural references. Select one strong idea that can shape the first viewport and recur subtly through the page.

Examples of useful translations:

- A trading-systems portfolio may borrow from market structure, terminal rhythm, order flow, and precise timing without becoming a fake Bloomberg screen.
- A ceramics storefront may use glaze, irregular silhouettes, tactile photography, and kiln heat as visual material rather than generic beige luxury styling.
- A scientific tool may let the data, experiment, or instrument become the visual anchor instead of adding abstract gradient decoration.

## Define a compact system

Before implementation, settle these decisions internally or record them in `DESIGN.md` when the project needs durable context:

- Visual thesis: one sentence explaining the memorable idea.
- Palette: named semantic roles for canvas, surface, primary text, muted text, border, accent, and status colors. Use a small set of actual values.
- Typography: one family or a clearly complementary pair, with roles, scale, weight, line height, and measure.
- Geometry: container widths, grid logic, spacing rhythm, radii, borders, and image treatment.
- Motion: the one orchestrated moment plus interaction feedback. Keep motion quiet when the content should lead.
- Asset plan: which real images, illustrations, textures, demos, or product captures carry the story.

Do not publish the design read as a long preamble unless the user asked to review direction before implementation.

## Compose the page

Make the first viewport express the subject and the primary promise. The hero may be typographic, photographic, interactive, product-led, or spatial; choose the form that best communicates the offer. Avoid forcing every brief into a centered headline, two buttons, and three feature cards.

Vary section composition according to information purpose. Repetition should create rhythm, not reveal a template. Use borders, numbering, labels, and cards only when they encode hierarchy, grouping, sequence, status, or interactivity.

Typography should carry personality while staying readable. Use display scale only where the page has room for it. Keep body measure comfortable, let copy wrap naturally, and test real words at narrow widths. Choose typefaces for the brief, not merely to avoid common fonts.

## Use assets as evidence

Visuals should show the actual product, object, person, environment, or idea whenever inspection matters. A dark blurred image or a fake dashboard rectangle is not a substitute for evidence. If final assets are unavailable, use clearly temporary content that preserves the intended composition and document the replacement point.

## Write interface copy

Use concrete nouns and active verbs. A headline names the product, person, place, or offer; supporting text explains value. Keep action names consistent across buttons, confirmations, and errors. Avoid decorative labels, invented statistics, vague superlatives, and copy that only describes the page's visual style.

## Run the specificity test

Before finishing, ask:

1. Could this palette, type, layout, and copy be moved unchanged to a different company in the same category?
2. Is each unusual choice connected to the subject or user task?
3. Is there one memorable idea, or many competing effects?
4. Did the implementation accidentally fall back to a repeated AI template?

Revise choices that are interchangeable. Remove effects that compete with the thesis.
